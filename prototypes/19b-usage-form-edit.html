1

表單檔案

唯讀
表單名稱（不可編輯）

僅更新表單資訊，不會變更表單檔案。

需要換檔請回使用表單管理使用該列之「更新／覆蓋上傳」——該路徑才會做跨文件引用之二次確認（USAGE_FORM_OVERWRITE_SHARED）。本頁儲存不會觸發該警示。

2

基本資訊

唯一性比對前 trim、不分大小寫，且排除自身列；清空為合法操作（落地為 null，清單該格回復「—」）。

3

制定部門

（選填，可多個）

可指定任意層級（本部／部／處室／課），各筆層級可不同。未勾選任何部門為合法（0 筆，非錯誤）。重新開啟本頁時原選取項完整回填，順序穩定（實作依 orgCode 昇冪）。

⚠ 本欄為純顯示與清單篩選用之 metadata，不影響任何可見性或權限判定（AC-N46）——與「文件使用部門」結構同構但用途完全不同，不得接進同一套子樹判定。

儲存只更新 表單編號 與 制定部門 兩項 metadata：blobPath / format / size / name / uploadedBy / uploadedAt 六欄逐欄不變、Blob 位元組未被讀取亦未被寫入、與文件之全部關聯不變，且不會觸發 USAGE_FORM_OVERWRITE_SHARED。
