## User Story

As a **後台使用者（尤其是主管層級）**,
I want **用一張環圖看出 ICSOP 文件的公告產出集中在哪些公司／本部／部門，而且預設就落在我這個層級該看的粒度**,
So that **我不必先選一堆篩選條件，就能看出哪一塊產出多、哪一塊還卡著**。

## 驗收意向（Acceptance Intent）

### AI-1 · 兩個區塊、同一套規則
**Given** 我進入後台首頁
**Then** 存在兩個環圖區塊，逐字標題為 `當月已公告` 與 `累積已公告`
**And** 兩者之頁籤、圖例格式、分組規則、組織名稱解析與預設頁籤判定**完全相同**
**And** 唯一差異為時間窗口：前者僅計當月，後者不限時間。

### AI-2 · 環之分段語意
**Given** 當前頁籤為「依制定公司」／「依制定本部」／「依制定部門」之任一
**When** 渲染環圖
**Then** 環之**每一段＝一個組織**（隨當前頁籤而定），以顏色區分
**And** ⚠ 待 `OQ-D44-16`——若裁為「環＝已公告／進度中兩段」，則三個組織維度頁籤失去意義，整個區塊須重新設計。

### AI-3 · 圖例格式
**Given** 環圖已渲染
**Then** 圖例每一列包含：色塊 ＋ 組織名稱 ＋ 該組織之「公告數量」與「進度中數量」**兩個數字**
**And** 🔴 **每一段與其數字必須以文字形式可讀**（[NFR-F044-2](../../F044-admin-dashboard-analytics.md)）——本輪無視覺回歸、無 e2e，數值若只存在於圖形幾何中即不可被驗證
**And** 「已公告」與「進度中」之區分**不得僅依顏色**。

### AI-4 · 組織名稱之標示層級
**Given** 頁籤為「依制定本部」
**Then** 每列須**標示所屬公司**（建議格式 `公司簡稱 / 本部名`）
**Given** 頁籤為「依制定部門」
**Then** 每列須**標示所屬公司與本部**（建議格式 `公司簡稱 / 本部名 / 部名`）
**And** 🔒 **必須沿用既有 `orgUnitDisplayName` 與 `ORG_PATH_SEPARATOR`，不得另寫第二套組裝**（⚠ 待 `OQ-D44-19` 附帶題）。

### AI-5 · 「制定本部」之推導
**Given** `ICSOP_DOCUMENT` **沒有**本部欄位（已查證：無 `draftingDivisionId`）
**When** 需要本部維度
**Then** 由 `draftingDeptId` 沿 `ORG_UNIT.parentCode` 上溯至第一個 `tier='DIVISION'` 之單位
**And** ⚠ 待 `OQ-D44-19`：無 `DIVISION` 祖先者之歸屬（建議＝歸入 `未指定`／`無本部` 段，**明文禁止排除**——比照 F042 `deptCodeOf()` 之既有取向「排除會使該文件在儀表板上完全消失，代價高於多一組」）。

### AI-6 · 無法解析之文件不得消失
**Given** 若干文件之 `draftingDeptId` 為 null
**When** 渲染任一維度之環圖
**Then** 該批文件仍須有明確歸屬（建議＝逐字 `未指定` 之獨立分段）
**And** 🔴 **環圖各段之總和必須等於該時間窗口下「已公告」之總數**——排除會使總和與 [US-109](US-109-dashboard-kpi-cards.md) 卡片之數字出現無法解釋的差額（⚠ 待 `OQ-D44-18`）。

### AI-7 · 預設頁籤依職位
**Given** 我的帳號有 `jobPositionCode`
**When** 首頁載入
**Then** 預設選取之頁籤為：`董事長`／`總經理` → 依制定公司；`本部長`／`副本部長` → 依制定本部；其餘一律 → 依制定部門
**And** 🔴 **判定必須先以 `(companyCode, jobPositionCode)` 解析出 `name`（明文禁止跨公司 fallback），再以 `name` 白名單比對**——直接比對 `code` 會在 AD 公司誤判（`B01` 在 AD＝`本處長`、`B03`＝`處長`、`C04`＝`部長`）
**And** ⚠ `副本部長` 目前**不存在於上游已記錄之職位名稱清單**（全 repo grep `副本部` 零命中）⇒ 該條目在真實語料下無載體，只能以人工 fixture 驗證純函式（⚠ 待 `OQ-D44-20`）。

### AI-8 · 手動切換
**Given** 預設頁籤已選取
**When** 我點擊另一個頁籤
**Then** 兩個區塊各自切換至該維度（⚠ 待 `OQ-D44-20` 子題 c——兩個區塊是否連動切換，交 ui-ux-designer 裁量並記入 spec）
**And** 頁籤列須具 `tablist`／`tab`／`tabpanel` 語意並可鍵盤操作（比照 F042 TAB bar）
**And** 切換之選擇**不跨 session 記憶**（⚠ 待 `OQ-D44-20` 子題 d）。

### AI-9 · 空狀態
**Given** 當月無任何已公告文件
**When** 渲染區塊 (1)
**Then** 呈現**明確之空狀態提示**，不得為空白畫布、不得為 0 段的環。

### AI-10 · 資料可見範圍
**Given** 我是四種後台角色之任一
**Then** 環圖統計之母體為**全量**（⚠ 待 `OQ-D44-21`）
**And** 若裁為限縮，須同時決定文件清單頁是否一併限縮（否則同一使用者在兩頁數出不同的總數）。
